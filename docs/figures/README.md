# Explanatory figures

The project logo is stored as `moweo-logo.png` in this directory and displayed
at the top of the main README.

Additional illustrations will be prepared separately from the software package
cleanup. The existing [architecture diagram](../architecture.svg) is conceptual,
not evidence of scientific accuracy. No new result images or screenshots are
claimed in this prerelease.

Planned illustrations:

1. AOI and 5 km tile grid, showing stable IDs and border tiles.
2. Detection and inner statistics masks over one example tile.
3. NDVI time series with candidate mowing dates and NDII/SWIR evidence.
4. Final count raster with a clear legend and NoData semantics.
5. A concise end-to-end example connecting inputs, commands and exported products.

Use English titles, legends and captions. Identify the year, data source and
code version. Distinguish synthetic examples from real outputs and detection
evidence from validated accuracy. Check rights before including imagery or
reference data; private masks must not be disclosed in screenshots. A synthetic
mask can illustrate the format when the project mask cannot be shared.

Prefer SVG for diagrams and exportable high-resolution images for actual maps
and scientific plots. Link completed figures from the main README only after
their content and captions have been reviewed.
