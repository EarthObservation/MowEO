# Release status

This repository is a prerelease source distribution, not a published DOI release.

| Component | Status |
|---|---|
| Source and packaging | Python modules, command-line interface, environment and dependency specifications included. |
| Documentation | English installation, AOI, masks, parameters, outputs, architecture and limitation guides included. |
| Automated verification | Offline source/installed-wheel tests passed; CI configuration included but not yet run on GitHub. |
| Explanatory illustrations | Architecture diagram included; additional real-output illustrations are planned separately. |
| Software license | Not assigned. The owner has deferred selection. |
| Scientific application | Regional calibration and version-linked independent validation remain necessary for accuracy claims. |
| Public repository and DOI | No public upload, tagged DOI archive or DOI citation metadata is claimed. |

Before a formal reusable open-source release, the owner must select the software
license, confirm rights to the inherited implementation, provide authorship and
citation metadata, and publish a reviewed, tested version. Archive that exact
version to obtain a real version-specific DOI; do not use placeholder identifiers.

Candidate-sample validation must not be described as population-wide accuracy.
Report the reference-data source, separation from calibration, sampling design,
uncertain cases and spatial/temporal matching rules. Keep application results
linked to a frozen code version, parameters, input vintages and process records.
